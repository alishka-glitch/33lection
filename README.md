
# Учебный веб-проект

## Описание проекта
Учебный веб-сайт, созданный в рамках практических занятий по веб-разработке.

## Основные возможности
- Просмотр главной страницы
- Навигация между разделами
- Просмотр информации о проекте
- Адаптивное оформление сайта

## Используемые технологии
- HTML5
- CSS3
- Git
- GitHub

## Структура проекта
- `erwww.html` — главная страница сайта.
- `README.md` — документация проекта.

## Запуск проекта
1. Скачать репозиторий.
2. Открыть папку проекта.
3. Запустить файл `erwww.html` в браузере.
